Export to JSON
Download all your logged days, milestones and weekly focus picks as a JSON file. Keep this as a backup - you can re-import it on any device. No account needed.
Import from JSON
Restore from a previous backup file. This merges with existing data - it will not delete or overwrite days you have already logged.

About this app
My Days v3.0 - four day types, six daily goals scored out of 100, and weekly milestones for the PhD and job hunt. Works fully offline. All data lives on this device in localStorage, so export a backup every Sunday.
Clear all data
Permanently delete all logged days. This cannot be undone. Export a backup first.
